# 工作台与消息

## 模块
- 工作台页面：`DashboardScreen.kt`
- 工作台状态：`DashboardViewModel.kt`
- 消息页面：`MessagesScreen.kt`
- 消息状态：`MessagesViewModel.kt`

## 功能分类
- 工作台总览指标
- 待处理任务列表
- 消息中心列表与定时刷新

## 具体实现

### 1. 工作台总览
- `DashboardViewModel.load()` 并发请求：
  - `dashboardRepository.loadOverview()`
  - `imageRepository.loadAllImageFiles()`
  - `authRepository.getCurrentUser()`
- 页面展示：累计患者、待处理影像、已完成影像、累计影像、完成率卡片。

### 2. 待处理任务
- 来源：影像列表中 `status in {UPLOADED, PROCESSING}`。
- UI：复用 `ImageTaskCard`，仅保留 `立即处理` 按钮。
- 跳转：与影像中心一致，进入影像分析页。

### 3. 消息中心
- 首次进入：`vm.load(..., silent = false)`。
- 定时轮询：`PeriodicTaskTrigger(intervalMillis = 60_000)` + `silent = true`。
- 列表项展示：标题、时间、内容。

### 4. 容错行为
- 工作台总览失败但影像成功时，仍展示待处理任务。
- 消息接口失败显示错误卡片，不阻断页面。
