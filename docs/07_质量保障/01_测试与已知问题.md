# 测试与已知问题

## 模块

- 开发规范：`AGENT.md`

## 功能分类
- 单元测试覆盖
- 已知问题记录
- 开发流程约束

## 具体实现

### 1. 当前测试覆盖
`ComposeAppCommonTest` 覆盖以下核心逻辑：
- `ThemePreferenceRepository`：
  - 更新并持久化读取
  - 非法存储值回退默认值
- `SessionStore`：
  - 会话 round-trip
  - clear 后为空
  - 损坏 JSON 返回 null

### 1.1 当前验证命令
- Android 单元测试：`./gradlew :composeApp:testAndroidHostTest`
- Android 构建：`./gradlew :androidApp:assembleDebug`
- iOS 编译校验：`./gradlew :composeApp:compileKotlinIosSimulatorArm64`

### 2. 当前缺口
尚未覆盖：
- ViewModel 行为测试（尤其 `ImageAnalysisViewModel`）
- Repository 网络契约测试
- Compose UI 交互测试

### 3. 已知问题
- `KNOWN_ISSUES.md` 记录过设备端网络权限导致的连接异常。
- 代码层面仍有跨平台能力未完成（以 `known-issues` 记录为准）。

### 4. 开发规范（项目内）
来自 `AGENT.md`：
- 后端 API 可能不稳定，开发前先用 `curl` 验证。
- 每次改动都要记录。
- 大改动后应立即提交。
