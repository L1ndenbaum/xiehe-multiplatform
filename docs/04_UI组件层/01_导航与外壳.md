# 导航与外壳

## 模块
- 总入口：`App.kt`
- 外壳：`ui/screens/MobileShell.kt`
- 顶栏：`ui/components/navigation/TopBar.kt`
- 底栏：`ui/components/navigation/BottomTabBar.kt`, `NavBar.kt`

## 功能分类
- 认证态与业务态路由切换
- 一级 Tab 导航
- 二/三级页面 Overlay 路由
- 返回键策略
- 页面与组件动画

## 具体实现

### 1. 路由层次
- 认证路由：`AuthRoute`（`LOGIN` / `REGISTER`）。
- 业务 Overlay 路由：`OverlayRoute`（患者详情、分析页、上传页、消息页等）。
- 一级 tab：`selectedTab`（工作台/患者中心/影像中心/个人中心）。

### 2. 导航原则
- 一级页切换通过底部 `NavBar`。
- 二/三级页通过 `OverlayRoute` 覆盖主壳。
- Android 返回键：
  - 有 overlay 时先关闭 overlay。
  - 认证页注册态时返回到登录页。

### 3. 顶栏行为
- 左侧：可选返回按钮。
- 右侧：支持图标按钮或文字按钮。
- 患者中心与影像中心右上角使用文字按钮：
  - 患者中心：`新增患者`
  - 影像中心：`上传影像`

### 4. 底栏动画
- 图标与文字颜色随选中态过渡。
- 点击图标时有“中心向外扩散”的短脉冲背景动画。
- 深色模式下影像分析页使用独立深色底栏配色。

### 5. 页面切换动画
- `App.kt` 中 `AnimatedContent` 用于：
  - overlay 进出动画（fade + slide）
  - tab 内容切换动画（fade + slide）
- 弹层类组件（PickerDialog、确认卡）统一支持淡入/滑入与淡出/滑出。
