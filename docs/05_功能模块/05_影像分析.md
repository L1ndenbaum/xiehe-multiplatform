# 影像分析

## 模块
- 页面：`ImageAnalysisScreen.kt`
- 状态核心：`ImageAnalysisViewModel.kt`
- 组件：`ui/components/analysis/*` + `ImageViewport.kt`
- 数据：`MeasurementRepository.kt`, `AiInferenceRepository.kt`, `ImageFileRepository.kt`

## 功能分类
- 影像显示与交互
- 手工测量/辅助图形
- AI 检测与本地六指标计算
- 标注导入/导出
- 报告生成与保存

## 具体实现

### 1. 页面生命周期
- 进入页面触发 `vm.load(fileId, ...)`：
  1. 拉取后端已有测量
  2. 下载影像字节
  3. 合并到 `ImageAnalysisUiState`
- `refresh()` 可重置状态并重载。

### 2. 工具体系（AnalysisToolsCatalog）
工具分组：
- 基础：移动
- 测量标注：T1 Tilt、Cobb、CA、Pelvic、Sacral、TS、AVT、标准距离、椎体中心、距离标注、角度标注
- 辅助图形：Circle、Ellipse、Box、Arrow、Polygon（双击收笔）

### 3. 手工测量计算
- `computeManualMeasurement()` 基于采点生成 `ImageAnalysisMeasurement`。
- TS/AVT：
  - 以两点投影到同一水平线
  - 主线段显示距离
  - 同时生成绿色虚线辅助段 `helperSegments`
- 标准距离：用于 px->mm 换算校准。

### 4. AI 检测与测量
- 入口：`runAiDetect()`。
- 流程：
  1. 上传当前 PNG 到 `/detect_keypoints`
  2. 解析关键点与椎体角点
  3. 本地计算六指标：T1 Tilt、CA、Pelvic、Sacral、TS、AVT
  4. 叠加关键点项（pose + vertebra corners）
  5. 覆盖当前测量层
- `runAiMeasure()` 当前直接复用 `runAiDetect()`。

### 5. 测量列表
- 分组显示：
  - `COMPUTED`（测量项）
  - `DETECTED`（关键点）
- 支持：
  - 全部显隐
  - 分组显隐
  - 单项显隐
  - 单项删除
  - 收起/展开动画

### 6. 报告
- 打开报告面板时会重新请求一次 `GET /measurements/{id}` 获取已保存报告。
- AI 生成报告：`POST /report-generation/generate`。
- 生成前二次确认，生成后覆盖 `reportText`。

### 7. 保存
- 保存接口：`POST /measurements/{image_id}`。
- 保存内容：
  - 计算测量项（非辅助图形、非占位）
  - AI 检测关键点（严格格式化 id/type/value/description）
  - `reportText` + `savedAt`
- 不会在保存时自动调用生成报告接口。

### 8. 导入导出
- 导出：将标注快照编码为 JSON 后下载保存。
- 导入：读取 JSON 并覆盖当前标注层。

### 9. 视觉规则
- 指标类型使用 `AnalysisMeasurementPalette` 分色（对齐 Web 端语义）。
- 关键点标记文字使用小字号绿色文本，避免遮挡。
