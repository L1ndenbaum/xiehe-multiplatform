# UI Refactor Batch 4: profile + message + dashboard

## 变更范围
- 重构 `screens/dashboard`：迁移 `DashboardScreen`。
- 重构 `screens/profile`：迁移 `ProfileScreen`、`AppearanceScreen`、`PersonalInfoScreen`、`ChangePasswordScreen`。
- 重构 `screens/message`：迁移 `MessagesScreen`。
- 重构 `viewmodel/dashboard`、`viewmodel/profile`、`viewmodel/message`：迁移 `DashboardViewModel`、`AppearanceViewModel`、`PersonalInfoViewModel`、`MessagesViewModel`。
- 重构 `components/message/shared`：迁移 `MessagePresentation`，并新增 `MessageCard` 承接消息页卡片展示。
- 新增 `components/card/dashboard`：将 Dashboard 中已成型的统计卡、快捷入口、待处理任务卡、近期动态卡从 screen 文件抽出。
- 新增 `components/card/profile`：将 Profile 页中的标签、统计项、菜单行抽出为独立组件。
- 更新 `App.kt` 与相关页面 import 到新 package。

## 兼容处理
- 继续保留前几批的共享桥接文件，供 cleanup 前未彻底收口的旧共享包路径使用。
- 本批的 Dashboard / Profile / Message 页面私有卡片已直接切换为新组件目录，不再保留旧 screen 内部定义。

## 说明
- 本批不改动工作台、消息中心、个人中心的业务行为，只调整目录、package、import，以及把已独立成型的卡片/列表项组件从页面文件中拆出归位。
