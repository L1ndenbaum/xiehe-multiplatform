# Android Launch Crash Fix

## 问题现象
- Android 端打开 App 后立即闪退。
- 崩溃栈定位到 `platformIconPainter`，异常为 `IllegalStateException: Android platform doesn't support SVG format.`。

## 根因
- Android 图标加载在上一轮 UI 改造中改为直接走 `composeResources` 的 `painterResource`。
- 当前 Android 运行时不会按该路径直接渲染 SVG，启动首屏 Header 图标时即崩溃。

## 修复内容
- 将 `composeApp/src/androidMain/kotlin/com/xiehe/spine/ui/components/icons/IconPainter.android.kt` 恢复为 Android 平台 `drawable` 资源映射实现。
- 为本轮新增 token 补齐 Android drawable 名称映射：`LAYOUT_DASHBOARD`、`HEART_PULSE`、`USER`、`USER_ROUND`、`USER_PLUS`、`BELL_RING`、`UPLOAD`、`SCAN_SEARCH`、`ARROW_RIGHT`。
- 保持 commonMain 资源与 Android 端生成的 `svg2vector` 资源兼容，不再在 Android 端直接加载 SVG 资源对象。

## 验证结果
- 执行：`./gradlew.bat :androidApp:installDebug`
- 结果：通过，并成功安装到设备。
- 执行：`adb shell monkey -p com.xiehe.spine -c android.intent.category.LAUNCHER 1`
- 结果：未再出现 `AndroidRuntime` 崩溃栈。
- 执行：`adb shell pidof com.xiehe.spine`
- 结果：返回运行中进程 `22342`。

## 影响范围
- 仅影响 Android 图标资源加载路径。
- 不涉及登录页、Dashboard、主 Tab 壳层的业务逻辑变更。
