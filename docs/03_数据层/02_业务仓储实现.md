# 业务仓储实现

## 模块
- `AuthRepository`
- `DashboardRepository`
- `PatientRepository`
- `ImageFileRepository`
- `MeasurementRepository`
- `NotificationRepository`
- `AiInferenceRepository`

## 功能分类
- 鉴权类接口
- 业务读取与分页
- 影像上传/下载/删除
- 测量保存与报告生成
- AI 检测/预测

## 具体实现

### 1. 鉴权仓储（AuthRepository）
主要接口：
- `POST /auth/login`
- `POST /auth/refresh`
- `POST /auth/register`
- `GET /auth/me`
- `PUT /auth/me`
- `GET /health/`

关键点：
- 会话本地持久化 + 自动 refresh。
- `withRefresh` 统一封装 401 刷新重试。

### 2. 工作台仓储（DashboardRepository）
主要接口：
- `GET /dashboard/overview`

关键点：
- 先直连，401 时刷新并重试。

### 3. 患者仓储（PatientRepository）
主要接口：
- `GET /patients/?page=&page_size=&search=&gender=&age_min=&age_max=`
- `GET /patients/{id}`
- `POST /patients/`
- `PUT /patients/{id}`

关键点：
- 查询参数按筛选条件动态拼接。
- 创建与更新请求使用结构化 DTO。

### 4. 影像仓储（ImageFileRepository）
主要接口：
- `GET /image-files`
- `GET /image-files?page=&page_size=`
- `GET /image-files/{id}/download`
- `POST /upload/single`（multipart）
- `DELETE /image-files/{id}`

关键点：
- 下载：缓存优先 + 单文件并发锁。
- 上传：multipart `file` 使用显式 Content-Disposition/filename；附带 `patient_id`、`exam_type`、`description`。
- 删除成功后同步清理缓存。
- 患者名回填：优先用缓存，缺失时按 patientId 补查并写回。

### 5. 测量仓储（MeasurementRepository）
主要接口：
- `GET /measurements/{imageId}`
- `POST /measurements/{imageId}`
- `POST /report-generation/generate`

关键点：
- 保存请求 `SaveMeasurementsRequest` 包含：`examType/imageId/patientId/measurements/reportText/savedAt`。

### 6. 消息仓储（NotificationRepository）
主要接口：
- `GET /notifications/messages?page=&page_size=`

关键点：
- 页面层通过定时任务组件每 60s 轮询刷新。

### 7. AI 推理仓储（AiInferenceRepository）
目标服务：`http://115.190.121.59:8001`

主要接口：
- `POST /detect_keypoints`
- `POST /predict`

关键点：
- multipart 文件字段固定为 `file`。
- 文件 part Content-Type 显式 `image/png`。
- `runAiMeasure()` 当前在 ViewModel 层复用 `runAiDetect()`。

### 8. 模型映射
- 全部 DTO 在 `data/*.kt`。
- 统一 `@Serializable` + `@SerialName` 对齐后端字段。
