# 通用组件

## 模块
- 反馈类：`ui/components/feedback/*`
- 输入类：`ui/components/input/*`
- 选择器：`ui/components/picker/*`
- 图标体系：`ui/components/icons/*` + `composeResources/drawable/*.svg`
- 头像：`ui/components/avatar/Avatar.kt`
- 影像任务卡：`ui/components/image/ImageTaskCard.kt`

## 功能分类
- 按钮/卡片/文本统一风格
- 加载遮罩与周期任务触发器
- 操作确认卡（可配置按钮色）
- 文本输入、筛选输入、日期滚轮选择器
- 跨平台图标资源管理
- 通用影像卡片（缩略图 + 状态 + 操作按钮）

## 具体实现

### 1. 反馈类组件
- `Button`：支持 icon、禁用态、按压缩放动画、可覆盖前景/背景色。
- `CompactButton`：小型胶囊按钮。
- `Card`：圆角 + 描边 + 内容尺寸动画。
- `LoadingOverlay`：居中转圈 + “正在加载中”，全屏半透明遮罩。
- `OperationVerifyCard`：可复用确认卡，确认/取消颜色由参数传入。
- `PeriodicTaskTrigger`：通用轮询触发器（消息中心每 60s 使用）。

### 2. 输入与选择器
- `TextField`：支持 leading/trailing icon、只读模式、密码模式。
- `FilterSelector`：下拉样式输入（右侧箭头 + 只读点击）。
- `DatePickerField`：点击后弹出滚轮日期选择器。
- `PickerDialog`：底部上滑到中间的通用容器，支持点击外部关闭。
- `WheelPickerColumn`：滚轮吸附选择实现。

### 3. 图标系统
- 统一枚举：`IconToken`。
- 资源映射：`IconToken.composeDrawable()`。
- Android：`IconPainter.android.kt` 使用 drawable 名动态解析。
- 其他平台：通过 Compose Resources `painterResource`。
- 当前 SVG 共 48 个，按功能命名：
  - `icons_action_*`
  - `icons_navigation_*`
  - `icons_status_*`
  - `icons_analysis_*`
  - `icons_measure_toolkit_*`

### 4. 头像组件
- 优先展示头像资源（`Painter`/`DrawableResource`）。
- 无头像时退化为名称字母头像。

### 5. 影像任务卡（核心复用组件）
- 组件：`ImageTaskCard`。
- 特性：
  - 左侧缩略图（下载字节后解码）
  - 顶部文件名/患者+检查类型/时间+状态
  - 底部操作按钮组（支持主按钮、描边按钮、危险按钮）
- 缩略图加载失败会尝试清理缓存并重试一次。
- 可用于：
  - 影像中心
  - 工作台待处理任务
  - 患者详情页影像记录
