# 登录与注册

## 模块
- 页面：`LoginScreen.kt`, `RegisterScreen.kt`
- 状态：`LoginViewModel.kt`, `RegisterViewModel.kt`
- 数据：`AuthRepository.kt`

## 功能分类
- 登录
- 注册
- 网络健康检查（调试可选）
- 登录态切换

## 具体实现

### 1. 登录页
- 输入：用户名/邮箱、密码。
- 行为：
  - 登录按钮 -> `LoginViewModel.submit()`。
  - 失败显示 `errorMessage` 与 `errorDetails`。
  - 跳转注册：`onOpenRegister`。
- 调试模式可显示 `/health` 自检按钮（`showNetworkDiagnostics`）。

### 2. 注册页
- 输入：用户名、姓名、邮箱、手机号、密码、确认密码。
- 校验：
  - 用户名 >= 3
  - 姓名 >= 2
  - 邮箱正则
  - 密码 >= 6 且两次一致
  - 手机（可选）要求 `+86` 前缀 + 11 位
- 提交成功后回登录页。

### 3. 状态管理
- `LoginUiState` / `RegisterUiState` 包含 loading、错误、成功提示。
- 登录成功把 `UserSession` 回传到 `App.kt` 并进入主壳。

### 4. 错误反馈
- 所有失败由 `AppResult.Failure.message` 驱动 UI。
- 网络错误由 `ApiClient.classifyNetworkError` 统一转换。
