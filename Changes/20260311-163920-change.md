# Login + Dashboard UI Refresh

## 变更范围
- 以 `NewDesign/NewDesign.pen` 为基准，重做登录页与工作台页面的视觉和结构。
- 主 Tab 统一切换到新的渐变 Header + 胶囊底部导航外壳。
- Patients / Images 页面将搜索框迁入新的 Header 区域，主体业务列表暂保留原实现。
- 新增登录 logo 资源、快捷入口/状态用图标资源，以及可复用 `IconBadge` / `ShellHeader` 组件。
- 工作台新增“近期动态”模块，首版复用通知消息接口映射展示。

## 保留的业务逻辑
- 登录流程继续使用现有 `LoginViewModel.submit` 与 `AuthRepository.login`，记住密码仍只保留本地 UI 状态。
- `/health` 连接自检入口继续可用，但仅在 `showNetworkDiagnostics=true` 时展示。
- Dashboard 数据仍以 `/dashboard/overview` 和影像列表接口为主，近期动态首版映射通知消息，不新增专用 dashboard API。
- Patients / Images / Profile 本轮只统一外壳，不重做原有主体业务逻辑。

## 验证结果
- 执行：`./gradlew.bat :composeApp:compileKotlinJvm`
- 结果：通过。

## 风险点
- Dashboard Header 右侧元信息本轮使用固定业务文案，未引入跨平台日期格式化能力。
- 主 Tab 外壳已统一，但 Patients / Images / Profile 主体内容仍为旧版结构，后续分页重构时需要继续对齐 `.pen`。
- 新增图标为本地离线资源实现，建议后续在 Android/iOS 真机再确认线宽和可读性。
