# 模块结构

## 模块
- 根工程：`settings.gradle.kts`
- 共享模块：`:composeApp`
- Android 启动模块：`:androidApp`
- iOS 壳工程：`iosApp`

## 功能分类
- `:composeApp`：跨平台共享业务模块（KMP + Compose Multiplatform）
- `:androidApp`：独立 Android Application 模块（规避 KMP + AGP9 兼容警告）
- `iosApp`：Xcode 工程，调用 `ComposeApp` framework

## 具体实现

### 1. 依赖关系
- `settings.gradle.kts` 仅包含 `:composeApp` 与 `:androidApp`。
- `androidApp/build.gradle.kts` 通过 `implementation(project(":composeApp"))` 依赖共享模块。

### 2. Source set 结构（`composeApp/build.gradle.kts`）
- `commonMain`：业务核心、共享 UI、主题、ViewModel、仓储。
- `androidMain`：
  - Android 平台适配（BackHandler、时间、epoch）
  - Android 图标 painter
  - Android 文件选择与下载保存
  - Android 二进制图片缓存实现
- `iosMain`：Darwin Ktor 引擎 + 占位输入输出适配。
- `jvmMain`：Desktop 入口 + 占位输入输出适配。
- `jsMain` / `wasmJsMain`：Web 平台入口 + 占位输入输出适配。

### 3. Android 启动壳
- `androidApp/src/main/kotlin/com/xiehe/spine/MainActivity.kt`
  - 从 `BuildConfig.BASE_URL` 注入后端地址。
  - 启动 `App(container = ..., showNetworkDiagnostics = BuildConfig.DEBUG)`。
- `androidApp/src/main/kotlin/com/xiehe/spine/AndroidAppContainer.kt`
  - SharedPreferences 实现 `KeyValueStore`。
  - 注入 `AndroidImageBinaryStore` 做持久化图片缓存。

### 4. 资源与图标
- 跨平台 SVG 源位于：`composeApp/src/commonMain/composeResources/drawable`。
- Android 构建时将上述 SVG 批量转换为 VectorDrawable：
  - 任务定义：`androidApp/build.gradle.kts` 的 `GenerateAndroidVectorsFromSvgTask`
  - 输出目录：`androidApp/build/generated/svg2vector/res/drawable`

### 5. 版本与依赖
- 统一版本管理：`gradle/libs.versions.toml`
- 关键版本：
  - Kotlin `2.3.0`
  - Compose Multiplatform `1.10.0`
  - AGP `8.11.2`
  - Ktor `3.2.3`
