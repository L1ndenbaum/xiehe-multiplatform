# Dashboard Pending Tasks Alignment

## 变更内容
- 对照 `NewDesign/NewDesign.pen` 的 Dashboard 待处理任务卡片，重做列表项信息层级。
- 列表项改为“患者名 + 检查类型标签”主行，以及“患者编号 · 时间 + 优先级”副行。
- 底部“查看全部影像”按钮补齐紫色描边，和设计稿保持一致。

## 数据修复
- 修复 `ImageFileRepository.loadAllImageFiles()` 未主动补全患者姓名的问题。
- 当影像列表接口未返回 `patient_name` 时，会基于 `patientId` 回查患者详情并回填缓存，保证 Dashboard 待处理任务能显示患者名。

## 涉及文件
- composeApp/src/commonMain/kotlin/com/xiehe/spine/ui/screens/DashboardScreen.kt
- composeApp/src/commonMain/kotlin/com/xiehe/spine/data/ImageFileRepository.kt

## 验证结果
- 执行：`./gradlew.bat :composeApp:compileKotlinJvm`
- 结果：通过。

## 说明
- 当前优先级文案仍基于现有影像状态字段推导，因为现有接口没有独立的任务优先级字段。
- 若后续后端补充真正的优先级字段，可直接替换 `pendingTaskPriority()` 的映射逻辑。
