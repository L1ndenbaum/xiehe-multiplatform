# UI Refactor Batch 1: auth + shared

## 变更范围
- 重构 `screens/auth` 与 `screens/shared`：迁移 `LoginScreen`、`RegisterScreen`、`MobileShell`、`PlaceholderScreen`。
- 重构 `viewmodel/auth` 与 `viewmodel/shared`：迁移 `LoginViewModel`、`RegisterViewModel`、`BaseViewModel`。
- 共享组件按新结构归位：`navigation/shared`、`icon/shared`、`form/input`、`form/picker`、`button/shared`、`badge/shared`、`avatar/shared`、`feedback/shared`、`card/shared`。
- 平台 `IconPainter.*` 同步迁移到 `components/icon/shared` 对应 source set。
- 更新 `App.kt` 与受影响页面/组件的 import 到新 package。

## 兼容处理
- 为了保证按批次提交时其余未迁移领域仍可编译，临时新增旧包桥接：
  - `ui/components/LegacySharedBridge.kt`
  - `ui/viewmodel/LegacyViewModelBridge.kt`
- 这些桥接仅用于过渡，后续领域迁移和 cleanup 批次会逐步删除。

- 结果：通过。
- 执行：`./gradlew.bat :androidApp:assembleDebug`
- 结果：通过。

## 说明
- 本批不改动业务逻辑，只变更目录、package、import 和必要的兼容桥接。
