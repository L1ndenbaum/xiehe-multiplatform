# 影像分析组件

## 模块
- 顶部栏：`AnalysisTopBar.kt`
- 底部栏：`AnalysisBottomBar.kt`
- 图像视口：`ImageViewport.kt`
- 测量结果面板：`MeasurementResultsPanel.kt`
- 工具面板：`MeasureToolPanel.kt`
- 设置面板：`AnalysisSettingsPanel.kt`
- 报告面板：`AnalysisReportPanel.kt`
- 色彩映射：`AnalysisMeasurementPalette.kt`

## 功能分类
- 顶/底工具栏操作
- 影像显示与手势（缩放/平移/点击采点）
- 标注绘制（点、线、虚线辅助线、辅助图形）
- 结果列表管理（显隐/删除/分组）
- 报告与设置弹层

## 具体实现

### 1. 顶部栏
- 左侧返回。
- 中部显示医生名、检查类型、影像ID/患者ID。
- 右侧布局：`保存按钮 + (导入, 导出)` 纵向双按钮。

### 2. 底部栏
- 四个动作：`AI检测`、`报告`、`工具`、`设置`。
- 固定深色背景，按钮为浅色文案+图标。

### 3. 图像视口（ImageViewport）
- 影像占满中间区域宽度，基于 `ContentScale.FillBounds` 绘制。
- 手势：
  - 双指缩放（内部 `gestureScale`）
  - 平移（`panOffset`）
  - 点击采点（工具驱动）
  - 双击结束 Polygon
- 约束：
  - 缩放不会低于容器宽度铺满（`renderedScale >= 1f`）
  - 平移 `clampPanOffset` 保证图像不脱离容器边界
- 绘制层：
  - 主测量线/点
  - AVT/TS 等辅助虚线
  - AI 关键点标签（小字号）
  - 指标标签（半透明底）
  - 待提交采点预览

### 4. 结果面板
- 顶部支持：
  - 全部显隐（eye）
  - 收起/展开（动画）
- 分组：
  - `测量项`（COMPUTED）
  - `关键点`（DETECTED）
- 每行支持：
  - 单项显隐
  - 删除（垃圾桶图标）

### 5. 工具与设置
- 工具面板按 section 分组（基础/测量标注/辅助图形）。
- 设置面板支持：
  - 清空测量
  - 缩放/对比度/亮度步进
  - 标准距离输入（默认 100mm）
  - 锁定图像

### 6. 报告面板
- 展示检查信息与报告正文。
- 右上角 `AI生成报告` 按钮。
- 保留多项报告字段展示位（当前多数字段为只读占位）。

### 7. 颜色体系
- 指标类型与颜色绑定由 `AnalysisMeasurementPalette.metricColors` 维护。
- AI 检测关键点、辅助虚线、草稿点分别使用独立颜色。
