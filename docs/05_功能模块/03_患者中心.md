# 患者中心

## 模块
- 页面：`PatientsScreen.kt`, `PatientDetailScreen.kt`, `PatientFormScreen.kt`, `PatientEditScreen.kt`
- 状态：`PatientsViewModel.kt`, `PatientDetailViewModel.kt`, `PatientFormViewModel.kt`, `PatientEditViewModel.kt`
- 数据：`PatientRepository.kt`

## 功能分类
- 列表检索、筛选、分页
- 患者详情展示
- 新增患者
- 编辑患者（增量更新）

## 具体实现

### 1. 列表与筛选
- 查询条件：搜索词、性别、年龄段。
- 筛选枚举：
  - `GenderFilter`：ALL/MALE/FEMALE
  - `AgeFilter`：ALL/0-18/19-40/41-60/60+
- 分页：
  - 首屏 `page=1,page_size=10`
  - 底部滚动加载更多 `loadMore()`

### 2. 患者卡片
- 信息：头像、姓名/性别/年龄、患者ID、电话。
- 按钮：`编辑` + `查看`。

### 3. 新增患者
- 关键字段：姓名、性别、出生日期、电话、身份证。
- 日期输入：`DatePickerField`（滚轮选择器）。
- 电话：前缀下拉 + 本地号输入。
- 校验：
  - 姓名最少 2 字
  - 出生日期 `YYYY-MM-DD`
  - `+86` 时本地号 11 位
  - 身份证 18 位数字/字母

### 4. 患者详情
- 展示基本资料与联系方式。
- 电话显示：前缀 tag + 主号码。
- 关联影像：调用 `imageRepository.loadAllImageFiles()` 按 `patientId` 过滤。
- 影像卡片复用 `ImageTaskCard`，仅保留 `立即处理`。

### 5. 患者编辑
- 首次加载患者详情映射到表单。
- 与 baseline 做 diff，仅提交变更字段（增量 PUT）。
- 无改动时直接提示“未检测到修改”。
