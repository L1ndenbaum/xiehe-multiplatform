# 个人中心与个人信息

## 模块
- 页面：`ProfileScreen.kt`, `PersonalInfoScreen.kt`, `AppearanceScreen.kt`
- 状态：`PersonalInfoViewModel.kt`, `AppearanceViewModel.kt`
- 数据：`AuthRepository.kt`, `ThemePreferenceRepository.kt`

## 功能分类
- 个人中心入口菜单
- 个人信息读取与增量更新
- 主题与模式设置
- 退出登录

## 具体实现

### 1. 个人中心（Profile）
- 展示医生头像/姓名。
- 菜单项：
  - 个人信息
  - 修改密码（当前占位）
  - 系统设置
- 底部提供退出登录按钮。

### 2. 个人信息页
- 首次进入流程：
  1. 先用 session 做 `seedFromSession`
  2. 再请求 `GET /auth/me` 刷新详情
- 编辑字段：真实姓名、手机号、职位、职称。
- 保存：
  - 与 baseline 对比，仅提交改动字段（`PUT /auth/me`）
  - 成功后同步更新 session 与界面

### 3. 外观设置页
- 品牌色切换：绿色 / 蓝色。
- 模式切换：跟随系统 / 按时间 / 浅色 / 深色。
- 持久化后即时生效（顶层 `SpineTheme` 读取 StateFlow）。

### 4. 修改密码
- 当前路由已预留，页面为 `PlaceholderScreen`。
- 后端功能完善后可直接替换页面实现，不需要改导航结构。
