# UI Refactor Batch 3: image

## 变更范围
- 重构 `screens/image`：迁移 `ImagesScreen`、`ImageUploadScreen`、`ImageAnalysisScreen`。
- 重构 `viewmodel/image`：迁移 `ImagesViewModel`、`ImageUploadViewModel`、`ImageAnalysisViewModel`，并同步归位影像域筛选类型、上传载荷、分析工具与测量模型。
- 重构 `components/card/image`：迁移 `ImageTaskCard`，保留影像列表卡片与 `inferExamType` 逻辑在影像域下。
- 重构 `components/analysis/image`：迁移分析页底栏、顶部栏、报告面板、设置面板、测量工具面板、结果面板、影像视口与调色板。
- 重构 `components/form/file`：迁移 `ImageFilePicker`、`JsonFilePicker`、`DownloadedFileSaver`，并同步迁移 Android/JVM/iOS/JS/Wasm 的 actual 实现。
- 更新 `App.kt`、`DashboardScreen`、`PatientDetailScreen` 和影像域页面 import 到新 package。

## 兼容处理
- 继续保留前两批引入的共享桥接文件，供未迁移领域使用旧共享包路径。
- 本批未新增影像域桥接，影像相关 screen / viewmodel / component 已直接切换到新结构。
