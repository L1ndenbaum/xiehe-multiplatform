# 其他平台现状

## 模块
- iOS：`composeApp/src/iosMain/*` + `iosApp/*`
- Desktop JVM：`composeApp/src/jvmMain/*`
- Web(JS/Wasm)：`composeApp/src/jsMain/*`, `composeApp/src/wasmJsMain/*`

## 功能分类
- 入口与壳层
- 网络引擎
- 平台适配能力完成度

## 具体实现

### 1. iOS
- 入口：`MainViewController()` + SwiftUI `ComposeView`。
- 网络：`iosMain.dependencies { ktor-client-darwin }`。
- 当前限制：
  - 文件选择器/下载保存为占位失败实现。
  - `PlatformBackHandler` 无实现。
  - `currentHour24()` 固定返回 12。

### 2. Desktop JVM
- 入口：`composeApp/src/jvmMain/kotlin/com/xiehe/spine/main.kt`。
- 文件选择器/下载保存为占位失败实现。

### 3. Web(JS/Wasm)
- 入口：`ComposeViewport`。
- 文件选择器/下载保存为占位失败实现。
- 图标走 Compose Resources。

### 4. 结论
- 当前只有 Android 具备完整业务链路（网络 + 本地缓存 + 文件上传下载）。
- 其余平台已具备编译入口与大部分共享逻辑，但缺少关键 I/O 适配。
