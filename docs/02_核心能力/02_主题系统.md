# 主题系统

## 模块
- 合同定义：`ui/theme/ThemeContract.kt`
- 调色板：`ui/theme/ThemePalettes.kt`
- 运行时：`ui/theme/ThemeRuntime.kt`
- Token：`ui/theme/ThemeTokens.kt`, `ui/theme/ThemeTypography.kt`
- 偏好存储：`core/store/ThemePreferenceRepository.kt`

## 功能分类
- 自定义语义色体系（非 Material3）
- 品牌色切换（GREEN / BLUE）
- 深浅模式切换（SYSTEM / AUTO_TIME / LIGHT / DARK）
- 全局 token 注入（颜色/排版/间距/圆角）

## 具体实现

### 1. 主题数据结构
- `SpineAppColors`：主色、背景、表面、边框、文本、状态色等语义槽。
- `SpineAppTypography`：display/title/body/subhead/caption。
- `SpineAppSpacing` 与 `SpineAppRadius`：统一布局 token。

### 2. 颜色方案
- `lightPalette(brand)` 与 `darkPalette(brand)` 都是手写 HEX。
- 当前提供两套品牌色：
  - `AppThemeBrandColor.GREEN`
  - `AppThemeBrandColor.BLUE`

### 3. 模式判定
- `ThemeMode.SYSTEM`：跟随 `isSystemInDarkTheme()`。
- `ThemeMode.AUTO_TIME`：20:00~次日07:00 使用暗色。
- `ThemeMode.LIGHT/DARK`：固定模式。

### 4. 偏好持久化
- 持久化键：`theme_preference`
- 存储格式：`<brand>|<mode>`
- ViewModel：`AppearanceViewModel` 直接驱动 `ThemePreferenceRepository`。

### 5. 全局使用方式
- 顶层 `App.kt`：`SpineTheme(preference = themePreference) { ... }`
- 子组件统一通过 `SpineTheme.colors / typography / spacing / radius` 取值。

### 6. 注意事项
- iOS 的 `currentHour24()` 当前固定返回 12，因此 `AUTO_TIME` 在 iOS 不准确。
- 组件实现中仍可能存在少量硬编码颜色（如影像分析深色底栏），后续可继续语义化。
