# 影像中心与上传

## 模块
- 页面：`ImagesScreen.kt`, `ImageUploadScreen.kt`
- 状态：`ImagesViewModel.kt`, `ImageUploadViewModel.kt`
- 数据：`ImageFileRepository.kt`, `PatientRepository.kt`

## 功能分类
- 影像列表展示与筛选
- 影像下载/删除
- 影像上传（关联患者与检查类型）
- 跳转标注分析

## 具体实现

### 1. 影像列表
- 搜索：患者名、患者ID、文件名、描述、模态等。
- 筛选：
  - 类型：ALL/XR/CT/MRI/OTHER
  - 状态：ALL/PENDING_REVIEW/ARCHIVED/PROCESSING/FAILED
- 列表组件：`ImageTaskCard`。

### 2. 卡片操作
- `标注分析`：进入 `ImageAnalysisScreen`。
- `下载`：
  - 先走 `ImageFileRepository.downloadImageBytes`（缓存优先）
  - 再走 `DownloadedFileSaver.save`
  - 成功后底部显示短时下载横幅。
- `删除`：
  - 弹出 `OperationVerifyCard` 二次确认
  - 确认后调用 `deleteImageFile`
  - 成功后刷新列表并清理缓存

### 3. 上传页
- 先加载全部患者（分页聚合）。
- 必填项：患者、检查类型、文件。
- 检查类型固定五类：
  - 正位X光片
  - 侧位X光盘
  - 左侧曲位
  - 右侧曲位
  - 体态照片
- 文件选择：`rememberImageFilePickerLauncher`。
- 提交接口：`POST /upload/single`（multipart）。

### 4. 性能与缓存
- 图片下载采用内存 + 持久化双层缓存。
- 缩略图按需加载，失败自动清缓存重试一次。
- 影像列表失败时可回退本地快照数据。
